# Expense Tracker (Python)

A simple command-line app to record daily expenses and see where your money goes. Data is saved in a CSV file, so it stays after you close the program.

## Features
- Add an expense (category, description, amount, date added automatically)
- View all expenses in a table
- Category-wise spending summary with total
- Delete an expense

## Concepts Used
- Functions and menu-driven programming
- File handling with the `csv` module
- Dictionaries and lists
- Exception handling (`try` / `except`)

## How to Run
1. Install Python 3 from python.org.
2. Run:
   ```
   python expense_tracker.py
   ```
